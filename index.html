About Blockverse

Blockverse is an original, self-contained voxel game platform built with Three.js. It ships a blocky third-person avatar, a physics-lite movement controller, a collision-aware orbit camera, a working world editor with an object explorer and a safe scripting layer, a local save/load/publish pipeline, and three playable demo games.
